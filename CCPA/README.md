# CCPA/CPRA Reference Library

**Author:** Joshna Yarlagadda

Generic, reusable CCPA/CPRA (California Consumer Privacy Act, as amended by the California Privacy
Rights Act) reference material and templates for security/privacy professionals building or
operating a privacy compliance program. Nothing in this folder is specific to any one
organization — copy what's useful into your own tracker and adapt it.

## Contents

- [`CCPA-CPRA-Framework.md`](CCPA-CPRA-Framework.md) — reference guide to applicability
  (revenue/data-volume thresholds, not location), key roles (Business, Service Provider,
  Contractor, Third Party, Consumer), the core obligations/rights catalog, an implementation
  roadmap, and a cross-mapping to GDPR, ISO/IEC 27001:2022, and SOC 2.
- [`controls.csv`](controls.csv) — 37 CCPA/CPRA obligations and consumer rights as a flat
  reference catalog (Ref, Category, Title, Description).
- [`templates/`](templates) — 17 fillable templates, including three CCPA/CPRA-specific artifacts
  with no direct ISO/SOC2/PCI equivalent: a Personal Information Inventory (replacing a generic
  asset inventory), a Consumer Request Log (tracking the 45-day statutory response clock), and a
  Cybersecurity Audit and Risk Assessment Log (the CPRA-mandated high-risk-processing program).
  See [`templates/README.md`](templates/README.md) for the full list and a suggested workflow.

## Relationship to the parent GRC repo

This folder lives alongside the ISO/IEC 27001:2022, SOC 2, and PCI DSS material (and any other
privacy-framework folders, such as GDPR) in the parent [`GRC`](../README.md) repo so all
frameworks' cross-mapping sections stay easy to cross-reference.
