# SOC 2 Reference Library

**Author:** Joshna Yarlagadda

Generic, reusable SOC 2 (AICPA Trust Services Criteria) reference material and templates for
security professionals building or preparing for a SOC 2 report. Nothing in this folder is
specific to any one organization — copy what's useful into your own tracker and adapt it.

## Contents

- [`SOC2-Trust-Services-Criteria-Framework.md`](SOC2-Trust-Services-Criteria-Framework.md) —
  reference guide to Type I/II reports, the Common Criteria (Security), the three optional Trust
  Service Categories, an implementation roadmap, and a cross-mapping to ISO/IEC 27001:2022, NIST
  CSF, and PCI DSS.
- [`controls.csv`](controls.csv) — all 43 Trust Services Criteria as a flat reference catalog
  (Criteria ID, Category, Title, Description).
- [`templates/`](templates) — 18 fillable templates covering the SOC 2 readiness-to-audit
  lifecycle: TSC controls matrix, asset inventory, risk register, internal audit checklist,
  evidence log, control exception register, policy inventory, access reviews, vendor risk,
  security objectives, onboarding/offboarding, BC/DR testing, legal & regulatory requirements,
  incident management, media handling, competence records, RACI, and compliance review. See
  [`templates/README.md`](templates/README.md) for the full list and a suggested workflow.

## Relationship to the parent GRC repo

This folder lives alongside the ISO/IEC 27001:2022 material in the parent
[`GRC`](../README.md) repo so both frameworks' cross-mapping sections stay easy to cross-reference.
