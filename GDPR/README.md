# GDPR Reference Library

**Author:** Joshna Yarlagadda

Generic, reusable GDPR (EU General Data Protection Regulation) reference material and templates
for security and privacy professionals building or operating a data protection program. Nothing in
this folder is specific to any one organization — copy what's useful into your own tracker and
adapt it.

## Contents

- [`GDPR-Framework.md`](GDPR-Framework.md) — reference guide to GDPR's extraterritorial scope, key
  roles (controller/processor/data subject/supervisory authority), the core catalog of principles/
  rights/obligations, an implementation roadmap, and a cross-mapping to ISO/IEC 27001:2022, SOC 2,
  and PCI DSS.
- [`controls.csv`](controls.csv) — 50 GDPR articles/obligations as a flat reference catalog
  (Article/Ref, Category, Title, Description), covering the data protection principles, lawful
  bases for processing, consent requirements, special category data, data subject rights,
  controller/processor obligations, security of processing, breach notification, DPIAs, the DPO,
  and international data transfers.
- [`templates/`](templates) — 18 fillable templates, including four GDPR-specific artifacts with
  no direct ISO/SOC2/PCI equivalent: a Records of Processing Activities Template (Art. 30), a Data
  Protection Impact Assessment Template (Art. 35-36), a Data Subject Request Log (Art. 12-22), and
  an International Transfer Register (Art. 44-49). See [`templates/README.md`](templates/README.md)
  for the full list and a suggested workflow.

## Relationship to the parent GRC repo

This folder lives alongside the ISO/IEC 27001:2022, SOC 2, and PCI DSS material in the parent
[`GRC`](../README.md) repo so all four frameworks' cross-mapping sections stay easy to
cross-reference.

---
*This is a reference framework, not legal advice. GDPR compliance obligations depend heavily on
the specifics of what personal data you process — consult qualified privacy counsel before relying
on any material in this folder as a complete or accurate statement of your legal obligations.*
