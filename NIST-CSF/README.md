# NIST CSF 2.0 Reference Library

**Author:** Joshna Yarlagadda

Generic, reusable NIST Cybersecurity Framework (CSF) 2.0 reference material and templates for
security professionals building or maturing a cybersecurity risk management program. Nothing in
this folder is specific to any one organization — copy what's useful into your own tracker and
adapt it.

## Contents

- [`NIST-CSF-2.0-Framework.md`](NIST-CSF-2.0-Framework.md) — reference guide to the six Functions
  (GOVERN, IDENTIFY, PROTECT, DETECT, RESPOND, RECOVER), the Current/Target Profile and
  Implementation Tier model, an implementation roadmap, and a cross-mapping to ISO/IEC 27001:2022,
  SOC 2, and PCI DSS.
- [`controls.csv`](controls.csv) — all 106 CSF 2.0 Subcategories as a flat reference catalog
  (Subcategory ID, Function, Category, Title, Description).
- [`templates/`](templates) — 18 fillable templates covering the CSF Profile lifecycle: a
  Current/Target Profile matrix, asset inventory, risk register, internal audit checklist,
  evidence log, gap register, policy inventory, access reviews, vendor/supply-chain risk, security
  objectives, onboarding/offboarding, BC/DR testing, legal & regulatory requirements, incident
  management, media handling, competence records, RACI, and Profile Review agenda. See
  [`templates/README.md`](templates/README.md) for the full list and a suggested workflow.

## Relationship to the parent GRC repo

This folder lives alongside the ISO/IEC 27001:2022, SOC 2, and PCI DSS material in the parent
[`GRC`](../README.md) repo so all four frameworks' cross-mapping sections stay easy to
cross-reference.
